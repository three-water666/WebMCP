# v1.1.0 (2026-09-05)

## 功能

- 新增持续可用的下一轮 follow-up 输入区，并将 follow-up 与工具活动统一到浏览器工作面板中，
  同时改进历史记录控制并稳定面板操作按钮。 (#75)
- 新增 DeepSeek 网络响应捕获与流式响应解析，并在工具活动中显示捕获来源，
  在 DOM 捕获之外提供基于网络响应的捕获路径。 (#76)

## 修复

- 工具活动条目更新时保持当前滚动位置，避免查看较早工具调用时发生滚动跳动。 (#73)
- 延长文件上传场景的自动发送重试处理，使结果投递能够等待更久的上传和输入区就绪状态，
  再决定放弃自动发送。 (#74)
