# v1.0.1 (2026-08-30)

## 功能

- 浏览器浮层新增可拖动的工具活动历史视图，使已完成的工具活动可以持续查看，
  同时不再要求当前活动区域固定占据原位置。 (#70)

## 改进

- 简化公开工具协议，移除 request ID，同时保持 DOM 重渲染期间工具调用追踪和
  结果关联的稳定性。 (#69)

## 修复

- 修复 DeepSeek 活跃轮次中的多条流式 DOM 工具调用捕获，避免前一条调用仍在
  处理时后续调用丢失。 (#71)
- Windows 命令风险检查现在对命令路径进行大小写不敏感比较，避免仅因路径大小写
  差异产生不一致判断。

## 工程

- 新增隔离的手动 QA 启动器，可构建当前 VS Code 与浏览器端源码，使用临时
  VS Code 环境启动，并支持独立浏览器 profile 和自定义 VS Code 安装路径。
- 更新评测与浏览器单元测试发现机制，使 Node 测试和递归发现的浏览器运行时测试
  能够自动纳入执行范围。
- 仓库 agent 与工作区 skill 文档调整为中文优先，同时保留对应的英文链接版本。
