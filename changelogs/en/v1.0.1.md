# v1.0.1 (2026-08-30)

## Features

- Added a draggable tool activity history view to the browser overlay so completed tool
  activity remains accessible without keeping the active activity surface fixed in place.
  (#70)

## Improvements

- Simplified the public tool protocol by removing request IDs while preserving stable
  tool-call tracking and result association across DOM rerenders. (#69)

## Fixes

- Preserved multiple streamed DOM tool calls within an active DeepSeek turn so later
  calls are not lost while earlier calls are still being processed. (#71)
- Made Windows command path comparisons case-insensitive in command-risk checks, avoiding
  mismatches caused only by path casing differences.

## Engineering

- Added an isolated manual QA launcher that builds current VS Code and browser sources,
  starts a temporary VS Code environment, and supports dedicated browser profiles and
  custom VS Code installations.
- Updated eval and browser unit-test discovery so Node tests and recursively discovered
  browser runtime tests are picked up automatically.
- Made repository agent and workspace skill documentation Chinese-first while preserving
  linked English counterparts.
