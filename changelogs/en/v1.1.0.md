# v1.1.0 (2026-09-05)

## Features

- Added a persistent next-turn follow-up composer and unified follow-up and tool activity
  into the browser work panel, with improved history controls and stable panel actions.
  (#75)
- Added DeepSeek network-response capture with streamed response parsing and capture-source
  indicators in tool activity, providing a network-based capture path alongside DOM capture.
  (#76)

## Fixes

- Preserved the tool activity scroll position while activity entries update, avoiding jumps
  while reviewing earlier tool calls. (#73)
- Extended auto-send retry handling for file uploads so result delivery can wait longer for
  upload and composer readiness before giving up. (#74)
